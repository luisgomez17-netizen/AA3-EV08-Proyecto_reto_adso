# Sistema de inventario

Proyecto base de la actividad AA3-EV08. Permite consultar productos, ver el detalle de un registro y abrir el formulario de registro.

## Cómo ejecutarlo

1. Copia esta carpeta dentro de `htdocs` en XAMPP.
2. Inicia Apache desde el panel de XAMPP.
3. Abre el navegador en `http://localhost/AA3-EV08-Proyecto_reto_adso_09102026/index.html`.

También puedes abrir `index.html` directamente en el navegador.

## Pantallas

- Inicio
- Listado de productos
- Registro de producto
- Detalle de producto

Los datos de ejemplo están en `assets/js/datos.js`. Este proyecto todavía no se conecta a MySQL.
